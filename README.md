# Peptide Bioactivity Post-processing Platform · Interface Showcase

Website: https://chenzy-655.github.io/peptide-activity-demo/

Read-only bilingual presentation of the local Python platform. English is the default on every page load. The university emblem and Chinese/English switch are retained. Seven workflow tabs can be browsed; analysis, inputs, uploads, filters, downloads and job actions are disabled.

The interface follows peptide_activity_app.py: analysis settings, composite weights, candidate ranking, algorithm comparison, single-peptide evidence, network layout, docking preparation and registry, report export and methods. Twelve illustrative sequences supply precomputed descriptors and sequence-rule scores. Sample-derived quantities, identification q-values, model predictions and spectra use placeholders rather than invented values.

This is an HTML/CSS presentation of the workflow, not the Python runtime. The core Python modules, model weights and experimental data remain private. Emblem provenance is in assets/logo-provenance.json.
